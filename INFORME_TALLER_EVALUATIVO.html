2. CONFIGURACIÓN INICIAL Y ESTRUCTURA DEL PROYECTO

Se desarrolló una solución modular en Python cumpliendo con la separación de responsabilidades entre la lógica del CRUD, las pruebas unitarias y la interfaz de usuario:

  • product_manager.py: Contiene la clase ProductManager con los métodos de manipulación de productos y persistencia JSON.
  • test_product_manager.py: Suite de pruebas automatizadas con unittest cubriendo casos válidos y excepciones.
  • main.py: Interfaz por terminal interactiva.
  • sonar-project.properties: Configuración para análisis estático en SonarQube.
  • productos.json: Almacén de datos persistente.

Operaciones CRUD y Pruebas Unitarias

3. IMPLEMENTACIÓN DEL CRUD

Cada registro cuenta con id (único), nombre, descripcion, precio (numérico no negativo) y cantidad (entero no negativo). Se implementaron los métodos:

  • crear_producto(): Inserta validando unicidad de ID y valores numéricos válidos.
  • obtener_producto() y listar_productos(): Consultas unitarias y masivas.
  • actualizar_producto(): Modificación selectiva de atributos con validaciones.
  • eliminar_producto(): Borrado físico seguro con verificación de existencia.
